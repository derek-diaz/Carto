# README screenshots

These images were captured from the Carto 0.9.0 interface using generated demo traffic. They do not contain workplace data.

- `discovery.svg`: automatic discovery and a JSON payload preview, dark theme.
- `inspector.svg`: horizontal subscription tabs, a selected stream row, the pinned evidence control, and a resized JSON inspector, dark theme.
- `publish.svg`: the compact JSON composer, collapsible observed keys, inline Options, and keyboard send shortcut, light theme.

Each SVG embeds the original screenshot and clips its frame to a 20-pixel corner radius. The rounded corners are part of the image, so the main README does not depend on inline CSS support. The captured interface itself is unmodified.

Refresh these screenshots when the workflows change. Keep the same filenames, use demo data, and check that text remains readable when the README scales images down.
